# 灵魂救星2 · 网页复刻版

韩国手游《灵魂救星2（Soul Saver 2）》的浏览器复刻版，纯前端单文件实现，打开网页即玩，无需安装。

## 在线试玩

https://soulsaver2.pages.dev

## 玩法与操作

| 操作 | 说明 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标左键 / 空格 | 普通攻击 |
| 1 / 2 / 3 | 技能（连击、范围、治疗） |
| E | 与 NPC 交互、推进对话 |
| C | 角色面板（属性、属性卡片、存档） |
| Esc | 关闭角色面板 |
| F | 自动挂机开关 |
| G | 切换挂机模式：待命 / 打小怪 / 交任务 |

## 已实现内容

- 三名可选主角：艾菲（双剑士）、里奥（精灵弓手）、艾米（法师）
- 四个场景：艾菲村、低湿地、阿依莲雪原、雪原首领战
- 完整主线任务链：接任务 → 自动寻路 → 打怪 → 交任务
- 自动挂机：A* 寻路 + 自动战斗 + 自动推主线，等级不够会自动刷小怪练级
- 属性卡片系统（5 张卡，可强化属性）
- 本地存档（localStorage，`soulsaver2_web_v1`），标题页可「继续上次存档」
- 角色面板「保存并退出」：存档后回到标题页，之后可以直接关掉网页

## 技术说明

- 单文件 HTML，原生 Canvas 2D + 原生 JS，无任何外部依赖
- 美术为按原作韩式厚涂风格重新绘制的原创素材，base64 内嵌，离线可玩
- 图片未加载时自动回退到程序化绘制，不会白屏
